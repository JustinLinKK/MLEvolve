# Qwen3.8-27B FP16 two-V100 local inference

## Settings

- Server: `Nautilus-V100`; Tesla V100-SXM2-32GB GPUs 0 and 1.
- Model: `Qwen/Qwen3.8-27B`; FP16 weights; two-GPU balanced Accelerate placement.
- Runtime: Transformers, PyTorch FP16, `torch.inference_mode`, generation KV cache.
- V100 memory upper bound: 30 GiB per GPU for model placement.
- Benchmark: one warmup and three streamed requests; 128 maximum new tokens; temperature 0.
- No fixed maximum parallel-job setting was used.

## vLLM attempts

| Configuration | Result |
| --- | --- |
| Exact INT8 W8A16 checkpoint, two GPUs | Rejected by vLLM: compressed-tensors kernel requires compute capability 7.5; V100 is 7.0. |
| FP16 base checkpoint, two GPUs, vLLM | API started; first request exhausted Triton Gated Delta Network kernel workspace at 95% GPU memory utilization. |
| FP16 base checkpoint, two GPUs, lower vLLM GPU memory utilization | 80% and 81% left no KV cache block. |

## Results

| Run | Median time to first token (seconds) | Median generation tokens per second | Median total seconds |
| --- | ---: | ---: | ---: |
| INT8, two V100 GPUs | 2.417 | 1.840 | 21.968 |
| FP16, two V100 GPUs | 1.303 | 4.781 | 9.450 |
